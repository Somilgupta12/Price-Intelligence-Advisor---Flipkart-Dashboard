# 🧠 Price Intelligence Advisor – Flipkart Dashboard

An interactive data visualization dashboard built using **Python** and **Tkinter**, designed to help users analyze and compare product pricing and ratings from Flipkart’s e-commerce data.

---

## 📌 Features

- 🔍 **Search Functionality** – Find products by name with detailed views.
- 🧮 **Profit Calculator** – Enter MRP and Selling Price to compute profit and discount.
- 🧾 **Category-Based Filtering** – Analyze product data by price range, rating, and category.
- 📊 **Dynamic Visualizations**:
  - Bar chart: Retail vs Discounted Prices by Category
  - Scatter plot: Price vs Rating with discount coloring
  - Histogram: Price Distribution per Category
  - Traffic Light System: Categorize products as Fairly Priced, Underpriced, Overpriced
- 📂 **Popup Windows** – For detailed product information and search results.
- ✅ **Responsive UI** with error handling and feedback.

---

## 🛠️ Technologies Used

- **Python 3**
- **Tkinter** – GUI framework
- **Matplotlib** & **Seaborn** – Visualization
- **Pandas** & **NumPy** – Data handling
- **CSV** – Dataset format
